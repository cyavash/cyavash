# HubL service-summary module

A small reference module for HubSpot website and landing-page work. It demonstrates editable repeater fields, optional descriptions and links, and escaped text output.

## Files
- `hubl-service-summary.html`: HubL markup
- `hubl-service-summary.css`: responsive card layout
- `hubl-fields.json`: field definitions

## Use
Create a local website module in HubSpot Design Manager, add the matching fields (or import the field definitions through your normal CMS tooling), then paste in the HTML and CSS. This folder is a source reference, not a complete installable theme.

Review the module in your portal before publication: test one and twelve cards, empty optional fields, long headings, mobile widths, keyboard focus and internal/external/email links. Native HubSpot compilation has not been verified for this public sample.

No client content, credentials or dependencies are included.
